# Car Market Analysis

## Project Overview

This project analyzes used-car data from Car Dekho to identify
important pricing patterns and market trends.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains information about:

- Car Name
- Manufacturing Year
- Selling Price
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Previous Owners

## Analysis Performed

- Present Price vs Selling Price
- Selling Price by Fuel Type
- Selling Price by Seller Type
- Selling Price by Transmission
- Manufacturing Year vs Selling Price
- Correlation Analysis
- Top Car Models by Selling Price

## Key Findings

- Present Price has a strong relationship with Selling Price.
- Diesel cars have the highest average selling price among fuel types.
- Dealer-sold cars have higher average selling prices.
- Automatic cars have higher average selling prices than manual cars.
- Newer cars generally have higher selling prices.
